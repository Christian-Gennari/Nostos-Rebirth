# Nostos Writing Studio Overhaul: Architecture & Polish Plan

> **For Hermes / Subagents:** Use this plan to overhaul Nostos Writing Studio into a serene, Nordic Editorial digital study that seamlessly matches the Library section.

**Goal:** Transform Nostos's Writing Studio from a barebones, disjointed three-column setup into a calm, unified, literary workspace aligned with the design manifesto, sharing the visual geometry, typography, and tactile restraint of the Library and Book Detail views.

**Architecture:** 
- Visual alignment with Library (`sidebar-collections`, `library.component`, `book-detail.component`): warm paper/stone surfaces, hairline borders (`1px solid var(--border-color)`), Newsreader serif for titles, Hanken Grotesk for UI controls/metadata, zero glassmorphism or SaaS artifacts.
- Left File Rail: Mirrors the library sidebar structure and collapse mechanics, using clean typography, refined flat tree styling, and calm action buttons.
- Center Paper Canvas: Centered physical-feeling manuscript sheet with optimal line length (60–75ch), distraction-free ambient typing, and a completely integrated, native-feeling TinyMCE / markdown editor with invisible-until-needed formatting affordances.
- Right Contextual Study Rail: Organic companion showing linked book notes, concepts, and scratchpad thoughts without cognitive overload or jarring tabs, allowing direct quote/excerpt insertion into the manuscript.
- Zen Mode: Pure editorial focus mode that gently recedes all peripheral chrome without abrupt layout shifts.

**Tech Stack:** Angular 21 (standalone components, signals, computed state, control flow `@if` / `@for`), CSS Custom Properties token graph, Lucide icons, TinyMCE + Turndown/Marked.

---

## 1. Architectural & Aesthetic Alignment with Library

The Library section is the gold standard of Nostos:
1. **Surfaces & Borders:** 
   - No `var(--glass-bg-strong)` or `backdrop-filter: blur()`.
   - Uses `var(--bg-sidebar)` for navigation panels, `var(--bg-body)` for room floors, and `var(--paper)` (`#ffffff` / `#1e1e1e` in dark mode) for the document sheet.
   - Thin hairline borders (`1px solid var(--border-color)` / `var(--rule)`).
2. **Typography & Hierarchy:**
   - Literary titles: Newsreader serif (`font-family: 'Newsreader', serif; font-weight: 500/600`).
   - UI chrome & labels: Hanken Grotesk sans (`font-family: 'Hanken Grotesk', sans-serif;`). Section labels use uppercase letter-spacing (e.g. `font-size: 0.75rem; letter-spacing: 0.08em; text-transform: uppercase; color: var(--color-text-muted)`).
3. **Buttons & Controls:**
   - Primary action buttons: `.btn.btn-primary` (solid pine accent, clean radius, crisp typography).
   - Quiet icon buttons: subtle hover states, no heavy pill buttons or neon glows.

## 2. Component-by-Component Transformation Plan

### Phase 1: Left Navigation Rail (Document Tree)
- **Current Issues:** Sits in a semi-transparent glass container, lacks section headers matching the library sidebar, uses generic icon buttons, transitions squash contents.
- **Proposed Improvements:**
  - Standardize container to use `var(--bg-sidebar)` with `1px solid var(--border-color)`.
  - Add collapsible rail behavior consistent with `sidebar-collections`: fixed rail axis, smooth collapse/expand, subtle count badges and clean tree node items.
  - Header with Newsreader title ("Studio"), subtle "New Document" / "New Folder" actions matching the Library's collection actions.
  - Refine `app-flat-tree` item styling for documents and folders: subtle tree guidelines, active file indicator matching the library's active pill.

### Phase 2: Center Manuscript & Editor Canvas
- **Current Issues:** TinyMCE feels like an external tool dropped into the middle of the screen; the toolbar and borders interrupt the sheet; word count pill is floating awkwardly.
- **Proposed Improvements:**
  - **The Paper Sheet:** Center the editor canvas on a virtual desk/paper sheet (`max-width: 820px`, centered with generous margins, soft ambient drop shadow matching book covers `box-shadow: 0 4px 20px rgba(0,0,0,0.06)`).
  - **Seamless TinyMCE Integration:**
    - Hide the static toolbar by default or tuck it into an ultra-minimal floating selection toolbar (Quickbars: bold, italic, heading, quote, link) that only appears when text is selected.
    - Remove the stark iframe outline; let the editable area blend directly into the document paper sheet.
    - Editable document title at the top of the manuscript in Newsreader serif (h1 style) seamlessly bound to the document name/title.
    - Floating / ambient status bar: quiet word count and save indicator in small Hanken Grotesk at the bottom corner of the study window, unobtrusive and non-flickering.

### Phase 3: Right Contextual Companion (Research & Book Notes)
- **Current Issues:** Clunky segmented tabs ("Concepts" vs "Books"), search input doesn't match library search, feels like database lookup rather than writing companion.
- **Proposed Improvements:**
  - Rename panel header to "Reference & Context".
  - Refined segment control matching Library's view toggle / filter chips: clean, subtle, calm stone background.
  - Search input styled identically to the Library's `search-bar-container`.
  - Notes cards: use the polished `NoteCardComponent` with quote styling, showing book source, author, and chapter.
  - **One-Click Thought Insertion:** Clean "Insert quotation" action that smoothly drops the excerpt into the active cursor position in the manuscript formatted as a markdown blockquote with citation.

### Phase 4: Focus & Zen Experience
- **Current Issues:** Fullscreen zen mode toggles classes abruptly and leaves an awkward exit button.
- **Proposed Improvements:**
  - Clean distraction-free view: both sidebars smoothly tuck away.
  - Paper sheet expands gently to optimal reading line length.
  - Ambient auto-fade: when the user starts typing, all chrome fades to 0% opacity; moving the mouse or pressing `Esc` brings controls back with a gentle ease.
